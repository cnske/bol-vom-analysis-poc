# < Project Name >

Proof of Concept (POC) of a ETL data-pipeline including analysis for monitoring data from Lake Bolmen and Lake Vomb, Sweden.

## Background and Introduction

< Shortly describe the issue and background of the project >

- monitoring of two important drinking water sources
- two different lakes - Bolmen humic, Vomb eutrophic
- no existing datapipeline for existing monitoring data

## Aim

Continuous monitoring is only useful if the gained data is able to give valuable insights, which can only be gained if the monitoring data is analyzed. Current circumstances limit the man power for manual analysis and an automated workflow and data-pipeline is necessary to allow for quick insights and current status of the two lakes.
The data-pipeline and workflow is supposed to be as modular as possible, to enable future modification and extension with other monitoring data.
